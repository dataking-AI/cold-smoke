# 滑雪录制坐标

录制按钮导出 `cold-smoke-ski-v1` JSON。所有世界位置和世界向量使用同一套固定的 FLU 坐标：

- X：雪场下坡方向，即游戏世界 −Z。
- Y：面向下坡时的左侧，即游戏世界 −X。
- Z：重力向上，即游戏世界 +Y。

位置原点为首帧两髋中点；坐标轴在整份录制中保持固定，不随人物转弯、起步朝向或地面法线转动。
`axes.reference` 为 `course_fall_line`，其余 `axes.run_*` 字段记录游戏世界中的原点和基向量。
人体关节、`human_pos`、速度以及地面位置、法线、切线和右向量均转换到这套坐标。
`gravity_body` 仍表示重力在人体局部坐标中的单位向量。

旧录制使用开始录制时人物朝向作为 X，其基向量已包含在各自的 `axes` 中；旧文件不会自动改写。
训练端应按完整 XY 位置和 `ground.normal` 查询局部地面，不能假设“同一 X 沿 Y 等高”。
雪场含有横坡、雪槽和局部起伏，固定下坡坐标轴不会把真实地形变成一维坡面。

时间插值使用逐帧 `t`。`requested_hz`、`measured_hz` 和 `dt` 不替代实际时间戳。
`ground.position` 取自物理状态的水平位置和地面高度，`ground_z` 是它在 FLU 中的 Z。

检查导出坐标约定：

```sh
node --test test/ski-export.test.js
```
